# 探索ラボ / Tansaku Lab

大学で学ぶ探索アルゴリズムを、日本語の説明・可視化・トレース表で学ぶ Web アプリです。React、TypeScript、Vite で実装し、ローカルでも Vercel でも動かせます。

## 起動

Node.js 24 LTS を推奨します（Node.js 26 でも動作します）。`.nvmrc` は24を指定しています。

```powershell
cd D:\SearchAlgorithms
npm install
npm run dev
```

表示されたローカル URL を開きます。通常は **http://127.0.0.1:5173/** です。

```powershell
npm test        # アルゴリズムの正しさを検証
npm run build  # TypeScript チェックと本番ビルド
npm run preview # dist/ のローカルプレビュー
npm run check  # 全テスト + 型チェック + 本番ビルド
```

## 収録したアルゴリズム

| 実験室 | アルゴリズム |
| --- | --- |
| 配列 | 線形探索、二分探索、ジャンプ探索、補間探索 |
| 迷路・経路（7方式） | 幅優先探索（BFS）、深さ優先探索（DFS）、反復深化探索、最良優先探索（Greedy Best-First）、Aアルゴリズム、ダイクストラ法、A* |
| 木 | 二分探索木、幅優先（レベル順）、深さ優先（先行順）、中間順 |
| 整列 | バブルソート、選択ソート、挿入ソート、クイックソート |

## 操作

- データ欄に −999〜999 の整数をカンマ・空白・改行で区切って入力し、「適用」を押します。配列は最大32要素、木は最大31ノードです。
- 探索対象を数値で入力するか、配列の要素・木のノードをクリックして設定します。
- 線形探索以外の配列探索では、入力を自動的に昇順に整列します。木は入力順に挿入し、重複値を除きます。
- 再生、一時停止、前後1ステップ、最後まで進む、速度変更（0.25〜16倍）、スライダーやステップ番号入力で実行を制御できます。反復深化では「次の深さへ」も使えます。
- キーボードは `Space` で再生／停止、`←` `→` で移動、`Shift`＋矢印で10ステップ移動、`Home` / `End` で最初／最後、`R` でリセット、`?` でガイドを表示します。入力中は通常の編集操作を優先します。カテゴリータブと迷路は矢印キーで移動でき、迷路の `Enter` / `Space` はマスの編集です。
- 擬似コードの対応行、探索状態の日本語解説、トレース表・比較回数の推移チャートが連動します。表は現在までの直近200ステップを表示し、行をクリックするとそのステップへ戻ります。スライダーでは全ステップへ移動できます。長いチャートは代表点を表示します。
- 「CSV」は未実行部分も含む全ステップを、UTF-8 BOM 付きでダウンロードします。
- 迷路ではクリック／ドラッグで壁・重みを編集し、編集ツールで始点・終点も動かせます。キーボードではマスにフォーカスし `Enter` で編集できます。
- 「アルゴリズム比較」は現在のデータで同じカテゴリーの全手法を実行し、確認回数や経路コストを比較します。反復深化の深さ上限と A の係数は、設定画面と同じ値を使います。

## 学習上の定義

- 配列の比較回数は、要素と目標値の3方向の比較を1回と数えます。境界チェックや添字の計算は含みません。
- 迷路は上下左右の4方向に移動します。BFS / DFS / 反復深化は重みを無視して1歩をコスト1と数えます。最良優先 / A / ダイクストラ / A* は重いマスへの進入をコスト5、通常のマスを1とします。始点のコストは0です。
- 反復深化は深さ上限を0から1ずつ増やす DFS です。循環するグラフ用に、反復ごとの最浅到達深さを記録し、同じか深い到達を省きます。最少歩数を求めます。この実装の保守的な上限は時間 O(d²(V + E))、補助空間 O(V + d) です。通常の木探索版の O(b^d) / O(bd) とは区別して表示しています。
- 反復深化の自動深さ上限は通行可能マス数−1で、手動では8・16・32・64・128を選べます。全迷路探索の累積訪問回数は30,000回を上限にします。制限による停止は「上限到達」とし、「経路なし」と区別します。
- 最良優先は、この教材では貪欲最良優先探索を指します。評価値 f=h（ゴールまでのマンハッタン距離）のみで次の候補を選び、g（実コスト）は記録しても選択には使いません。最小コストを保証しません。
- Aアルゴリズムは f=g+h の一般形で、ここでは h=α×マンハッタン距離を使用します。係数は0・0.5・1・1.5・2・3・5から選べ、初期値は2です。α=0はダイクストラ法、α=1は既存の A* と同じ探索になります。0≤α≤1で最小コストを保証し、α>1では保証しません。より良い g が見つかると探索済みノードも再展開します。トレースと CSV に g・h・f を含めます。
- A* はマンハッタン距離を使います。ダイクストラ / A* の最小値選択には配列を使うため、この実装の時間計算量の上限は O(V² + E) です。
- 木の高さの表示は根を1段目とする段数です。BST 探索の時間は高さ h に対して O(h) で、平衡なら O(log n)、最悪 O(n) です。
- 補間探索の最悪は O(n)、一様に分布する場合の平均は O(log log n) です。
- クイックソートは末尾ピボットの Lomuto 法と明示スタックを使います。平均 O(n log n)、最悪 O(n²) です。
- 計算量はアルゴリズム自体のものです。可視化用に全ステップのスナップショットを保持するため、アプリ全体のメモリ使用量とは異なります。
- コード欄は学習用の Python 風擬似コードです。データ構造の補助関数を省略しているため、そのまま実行するコードではありません。

バックエンド・アカウント登録は不要です。表示設定・前回の実験・学習記録は、それぞれのブラウザーの `localStorage` に保存します。画面のフォントには Google Fonts を使用し、オフラインではシステムフォントに切り替わります。

## 表示と操作のカスタマイズ

上部またはサイドバーの「表示設定」から変更できます。設定は即時反映され、再読み込み後も維持します。

- テーマ：システム追従、ライト、ダーク、ペーパー。クイック切替ボタンもあります。
- アクセント：グリーン、ブルー、バイオレット、アンバー。
- 文字：80〜160%（5%刻み）、Noto Sans JP／端末標準／明朝体。上部の A− / A＋でも変更できます。
- 配置：横並び、縦並び、集中。横並びの可視化幅（45〜80%）とコードの左右を調整できます。狭い画面は自動で縦並びになります。
- 画面幅、サイドバーの折りたたみ、表示密度、コード・統計・トレースの表示を選べます。集中レイアウトは紹介とコードを隠し、可視化を広く使います。
- 色に加えて枠線・模様で状態を区別する表示、アニメーション軽減、トレース追従、タブ移動時の一時停止、ループ再生を設定できます。
- 対応ブラウザーではツールバーから全画面表示ができます。設定ダイアログ内にキーボードフォーカスを保持し、`Escape` で閉じます。

「表示設定を初期値に戻す」は表示・操作設定だけをリセットし、実験と学習記録は保持します。

## 実験の保存・共有・やり直し

- 実験は自動保存され、次回は停止した状態で復元します。「次回、前の実験を復元する」で無効化できます。カテゴリーを戻ると、前に選んだアルゴリズムを覚えています。
- ツールバーの「元に戻す」「やり直す」はデータ、目標、迷路の編集を30回分保持します。迷路のドラッグは1回の操作として扱います。`Ctrl / ⌘ + Z`、`Ctrl / ⌘ + Shift + Z`、`Ctrl + Y` も利用できます。履歴はページを閉じるまでです。
- 「サンプル」から初期データ、逆順、重複、負数、偏った木、重み付き迷路などを読み込めます。整列が必要な探索では昇順に調整します。
- 「実験を保存」は設定とデータを JSON に書き出します。「実験を読み込む」は64 KB以下のファイルを検証し、不正なデータなら現在の実験を維持します。
- 「実験を共有」はリンクのハッシュ部分に実験を含めます。共有には表示設定、XP、学習記録を含めません。受け取ったリンクは読み込み後に通常のURLに戻り、その後の変更は自動保存されます。
- 擬似コードのコピーボタンと、全ステップの CSV 書き出しを利用できます。

## 学習の冒険（ミニRPG）

サイドバーのカードや「学習の冒険」から、レベル・XP・日々の達成・宝物・実績を確認できます。

- 日付は **日本時間（Asia/Tokyo）** で区切ります。再生やステップ操作で最終結果まで到達すると、そのアルゴリズムを体験した記録が残ります。「未発見」も学習として記録し、「上限到達」は対象外です。
- **1アルゴリズムにつき1日1回20 XP**。同じ方式を繰り返しても重複加算しません。100 XPごとにレベルが上がります。
- **1日3種類** を体験すると、デイリー宝箱を開けられます。1日1個、報酬は **50 XP と記念アイテム**。開封状態を保存し、再読み込みでも重複して受け取れません。
- 連続学習日数、最長記録、直近7日間の学習を表示します。当日まだ学んでいなくても、前日までの連続記録を表示します。
- 初回体験、5種類・10種類・全種類、1日3種類、3日・7日連続、初回宝箱・5個開封の **9実績** があります。過去の体験済みアルゴリズムは実績に引き継ぎ、XPは追加後の学習から加算します。
- 同じブラウザー内の別タブとは記録を同期・統合します。サーバーや他の端末には同期しないため、ブラウザーのサイトデータを削除すると記録は失われます。

## Vercel へのデプロイ

環境変数やバックエンドは不要です。公式の [Vite デプロイ手順](https://vercel.com/docs/frameworks/frontend/vite)に沿って設定済みです。アカウントの作成・ログインと公開操作は利用者が実施します。

1. このプロジェクトを GitHub / GitLab / Bitbucket のリポジトリへ push します（`node_modules`、`dist`、`.vercel` は含めません）。
2. Vercel の **Add New → Project** でリポジトリをインポートします。
3. **Root Directory** に `package.json` と `vercel.json` のあるディレクトリを指定します。このフォルダー全体をリポジトリのルートにした場合は `.` です。
4. 以下の設定を確認して **Deploy** を実行します。

| 項目 | 設定 |
| --- | --- |
| Framework Preset | Vite |
| Node.js | 24.x（Vercel が対応する24系） |
| Install Command | `npm ci` |
| Build Command | `npm run check` |
| Output Directory | `dist` |
| Environment Variables | なし |

`vercel.json` がインストール・ビルド・出力先を指定します。ビルド前に全テストが実行され、テストか型チェックに失敗した場合はデプロイを止めます。SPA の URL を直接開き直せるよう、`index.html` へのフォールバックも含めています。

CLI を使う場合は、このディレクトリで以下を実行します。初回は Vercel のログインとプロジェクト選択が必要です。

```powershell
npm run check
npx vercel          # プレビューデプロイ
npx vercel --prod   # 本番デプロイ
```

公開後はトップページ、配列探索、反復深化・最良優先・A の選択、再生、トレース、CSV 出力を確認してください。学習進捗は各訪問者のブラウザーに保存されます。

参考：[CMU の探索アルゴリズム講義](https://www.cs.cmu.edu/~15281-f23/coursenotes/search/index.html)、[Vercel の設定リファレンス](https://vercel.com/docs/project-configuration/vercel-json)。

ブラウザーはモダンな Chrome、Firefox、Edge、Safari を想定しています。
